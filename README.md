# TypeArena

Created and maintained by Ronaldo Laishram.

An invite-only multiplayer typing platform, developed from a
local Python application into a Cloudflare-hosted web app.

## Features
- Synchronized multiplayer typing races
- Shared passages and multiple difficulty levels
- WPM and accuracy rankings
- Administrator invitations and player management
- Responsive room chat
- Profiles, practice, achievements, and certificates
- Themes and sound effects

## Technology
HTML, CSS, JavaScript, Cloudflare Workers,
Durable Objects, WebSockets, and D1.

## Live application
https://arena.claimsquare.in

Competition access requires an administrator invitation.

## My contribution
Product concept, competition rules, feature direction,
interface decisions, testing with friends, deployment,
and ongoing improvements.

Development involved AI-assisted coding.
